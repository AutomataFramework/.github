# Automata Framework

Make 2D games that run the same way every time.

Automata Framework is free and open source, and always will be. A game is a folder of plain files plus a
little code. Play the same game with the same moves and it ends the same way, on any computer or browser,
so you (or a helper like Claude) can change a game and prove nothing broke.

**Start here:** [automataframework.com](https://automataframework.com)

## Make a game

The [framework's README](https://github.com/AutomataFramework/AutomataFramework#start-here) walks you
through your first game, step by step.

## Automata Suite

The editors for making games on an iPad, a phone or a computer are called Automata Suite. They are sold
separately. The framework stays free.
