# Automata Framework

Free tools for making 2D games with an AI helper, on a computer or an iPad.

- **Free forever.** The framework is open source and always will be.
- **Made for AI helpers.** A game is a folder of plain files plus a little code. Every new game tells a helper like
  Claude where things are, and one command says in plain words whether the game still works.
- **Six languages.** Write your game's words once. It ships in Chinese, Spanish, English, Portuguese, Japanese and
  Korean, and each player picks their own.
- **Keys or touch.** Games play in a browser on a computer, a phone or a tablet.

**Start here:** [automataframework.com](https://automataframework.com)

## Automata Suite

Automata Suite is the set of editors for making games on an iPad, a phone or a computer. When you save, your
changes go straight into your game's GitHub repo. The editors are sold separately. The framework stays free.
